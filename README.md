# Bookshelf

Bookshelf is a system that allows library members to search for, browse, and reserve books available across all libraries within a library network. Its intuitive and user-friendly interface enables users of all ages to navigate the application and utilize the library system's services easily and efficiently.

The application allows users to check the availability of a specific book and reserve it, if desired, before visiting the library to borrow it. This saves members from having to visit multiple libraries in cases where the requested book is not in stock or is already on loan or reserved. To begin using the system, users log in with the credentials provided upon registration to verify their membership. Once logged in, they can access the system's full range of features.

After logging in, users can search for books available within the library network. Search results display a list of relevant books, offering options to view book details or check the selected book's availability across all libraries in the system.

By viewing book details, users can see information such as the author, publisher, and year of publication; this helps them distinguish between different editions of the same work and easily select the specific edition they are looking for.

By checking the availability of a selected book across the network, users can identify which libraries hold the title and see exactly where the requested book is currently available. Additionally, viewing information about specific libraries allows users to discover nearby branches they may not have previously known existed. Information regarding the name, street address, telephone number, and opening hours of the selected library is provided.

For books that are in high demand and often unavailable at libraries, the system offers a reservation feature; this prevents members from making a wasted trip to the library when all copies of the desired book are already on loan. The user's session concludes upon logging out of the system.
